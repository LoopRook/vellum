Spacing scale

Eight steps on a 4px base. Bars are drawn at true size from the token values, so the scale you see is the scale that ships.

Radius as identity

Radius says what a thing is, not how large it is. Two components sharing a radius are the same kind of object — a pill is fully round because it is a capsule, a mode button is small-radius because it is a machined part. Choosing by eye breaks the grammar even when it looks fine.

Blur as elevation

Depth is expressed by blur, and the ordering is fixed. Rungs may be skipped — a page with no stage is fine — but never reordered, and never extended with a new value.
