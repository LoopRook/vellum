Vellum is a toolkit, not a template. Two sites built from it should look nothing alike and still read as the same system. The left column is what makes that recognition possible — break one and the artifact stops being Vellum. The right column is yours. Fix any of it across every project and you have built a template instead.

The line

Constants

[ Invariant · every artifact ]
01 · Type carries hierarchy

Geist 800–900 for display, Inter for prose, JetBrains Mono for every mechanical label — uppercase, always. Never colour as hierarchy.

02 · Monochrome headlines

Display type is --color-text-primary or its inverse. No tint, no gradient, no accent word.

03 · The elevation ladder

Blur expresses depth, and the order never changes. Rungs may be skipped, never reordered.

04 · The material has physics

Blur belongs to the sheet, never to text. In light mode every sheet edge is exactly 1px and uncoloured; in dark it is zero. The lamps, two or three per mode, are what a sheet diffuses — without them every surface flattens.

05 · Hover is quiet

Lift 2px; in light mode the edge also brightens. No glow, no colour shift, no scaling.

06 · Accents are status, not brand

Action colour is monochrome ink that inverts across modes. The status colours report live state only — never a button fill, never a headline.

07 · Pill grammar is binary

Untinted means category. Tinted means live state. If the label would read the same tomorrow, it is a category.

08 · Radius encodes identity

Radius says what a thing is, not how big. Same radius means same kind of object. Choosing by eye breaks the grammar.

09 · Focus is monochrome

Ink border plus --color-focus-ring halo. Browser-default blue is prohibited; so is removing focus entirely.

10 · Paper is not a screen

Print drops every digital artifact. Structure survives as 0.5pt hairlines and 100% K type — the hierarchy is what makes it a sibling.

Variables

[ Free · per project ]
Layout & composition

Section count and order, grid structure, page length, whether there is a hero, a stage, or a console at all. The system has no required page shape. A single-column editorial page with none of the demo furniture is fully on-brand.

Content & voice

All yours. Telemetry readouts and frame rates belong to the product the examples demonstrated — not to the system. Labels stay uppercase mono; what they say is the project's.

The project accent

--color-accent is designed to be repointed. Set it to anything. It stays bound by constant 06 — which is exactly why a magenta-accented site still reads as Vellum. The accent was never carrying the brand.

Lamp hue

The lamps' hues are yours, under the opacity ceiling in semantic.lamp. Each is an opaque colour at an opacity, per mode. Fixed: that there are two or three per mode, that they sit behind everything with nothing beneath the table, and that they stay ambient rather than decorative.

Density & imagery

Which spacing steps you favour, how much air the layout carries, photography or illustration or nothing, and which glyphs you draw on.

Medium

Web, application, deck, print, stationery, email. The grammar survives all of them; constant 10 governs the crossing to paper.

Where the demo's layout went

The landing example's ten sections, 560px stage, 2×2 feature grid and four-column stat bar are that example's anatomy — documented in examples/landing/ANATOMY.md. Reproduce it if it suits the work; ignore it freely if it does not. An example is a reference to check output against, not a starting point.

The audit — any single failure means off-brand
TypeGeist 800–900 headlines on a display tracking role; every mechanical label uppercase mono?
Monochrome headlinesNo tint, gradient, or accent word anywhere in display type?
Action colourEvery primary action monochrome ink, inverting between modes?
Accent disciplinePoint at any accent and name the state it reports. No answer means it fails.
Pill grammarCategories untinted, tint reserved for live state?
ElevationLadder in order, consoles nested inside cards, cavities opaque and unblurred?
Sheet integrityText sharp on the sheet, borders exactly 1px and uncoloured in light and zero in dark, two or three lamps present per mode?
Quiet hoverA lift, and in light mode a brighter edge — no glow, no hue on the border, no scaling?
FocusMonochrome ring on keyboard navigation, no browser default?
Not a templateLayout driven by this project's content, not copied from an example?
On the last question. A page can pass every style check and still fail the system. If the layout reproduces an example's section order without the content needing that order, the artifact is a copy of an example wearing the grammar — not a new Vellum artifact. That distinction is the whole point of this page.
