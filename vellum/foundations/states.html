What Each State Does
  • 1. Default (Idle): The control at rest.
  • 2. Hover (Elevated): The pointer is over the control. It lifts by translateY(-1px) and its border turns ink, var(--color-text-primary).
  • 3. Active (Pressed): The control is being clicked or tapped. It presses in by translateY(1px) scale(0.98).
  • 4. Focused (Keyboard Navigation): Reached with the Tab key. A ring using a 2px solid var(--color-text-primary) outline with 2px offset (never browser default blue/yellow rings).
  • 5. Disabled: The control cannot be used. It drops to opacity: 0.38 with cursor: not-allowed, and keeps its place in the layout.
